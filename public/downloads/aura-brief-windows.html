AURA — Early-stage Web3 Project

We have an idea. We're building it.

AURA is an early-stage Web3 ecosystem exploring digital identity, NFTs, token economics and community.

What exists

  • AURA identity and brand
  • AURA #001 — ORIGIN on Ethereum
  • AURA #002 — FORCE on Ethereum
  • Public investor/developer website
  • Node.js / Express engineering foundation
  • NFT/API/Web3 integration foundation

What is being built

  • Core product and platform
  • Identity architecture
  • Backend and production infrastructure
  • Further Web3 functionality
  • Community and participation layer

Windows developer start

Install Node.js, clone the public repository, then run npm install and npm start in PowerShell or Command Prompt. The public foundation is designed to run without private credentials.
