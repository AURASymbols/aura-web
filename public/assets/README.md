# AURA Artwork Assets

The production site expects these artwork files in this directory:

- `aura-001-origin.png`
- `aura-002-force.png`

They are the actual AURA #001 — ORIGIN and AURA #002 — FORCE artwork used by the v1.6 local project.

The connected GitHub interface currently supports UTF-8 text uploads directly; binary artwork files should be uploaded to this folder through GitHub's web interface if they are not yet present.
