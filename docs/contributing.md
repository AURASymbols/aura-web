# Contributing to AURA

AURA is an early-stage project. Contributors are not joining a finished specification; early builders can help shape the specification itself.

## Who we are looking for

### Developers / Builders

Useful areas include:

- Frontend engineering
- Node.js / backend engineering
- Database and API design
- Web3 / blockchain integration
- Smart contract engineering when required
- Security and testing
- Product engineering and UX

### Product / Architecture

We also welcome people who can help answer the harder questions before code is written:

- What should the first useful AURA product be?
- What should identity mean inside AURA?
- Which data belongs on-chain and which belongs off-chain?
- What should be built first?
- What should deliberately wait?

## Working principles

1. **Be honest about status.** Do not present planned features as deployed features.
2. **Prefer evidence over hype.** Link to real work where possible.
3. **Keep architecture understandable.** Avoid complexity without a clear reason.
4. **Protect users.** Security, privacy and user control matter from the beginning.
5. **Document important decisions.** The project should become easier to understand as it grows.
6. **Challenge assumptions.** Early contributors are expected to question the plan when evidence suggests a better direction.

## Current contribution opportunities

The most useful early contributions are likely to be:

- Review the architecture direction
- Propose a practical backend structure
- Define an initial data model
- Identify the first useful API endpoints
- Review Web3 integration options
- Improve testing and deployment practices
- Help turn roadmap items into small, verifiable tasks

## Development flow

```text
Question
  -> Proposal
  -> Small implementation
  -> Test / review
  -> Evidence
  -> Decision
  -> Next step
```

## Important note

AURA is early-stage. There is currently no promise of compensation, investment, employment, token allocation, or future return merely from contributing. Specific arrangements should be discussed and agreed separately before work begins.

## Getting started

Clone the repository, install dependencies, and run the local server:

```bash
npm install
npm start
```

Then open `http://localhost:3000`.
