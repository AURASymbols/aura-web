# AURA — Early Developer Opportunities

AURA is inviting technical review and small, clearly scoped contributions. These are areas where help is useful; they are not paid job postings or guarantees of compensation.

## Current project context

AURA is an early-stage Web3 project. The repository contains a public web portal, a Node.js / Express foundation, documented API routes, an early Ethereum integration and two published ERC-1155 NFTs. The complete platform is not deployed.

Read first: [Project overview](project-overview.md), [Developer FAQ](developer-faq.md), [Technical architecture](architecture.md), [API documentation](api.md), [Contribution guide](contributing.md).

## Priority contribution areas

### Backend foundation
Review route organization, error handling, input validation and tests. Related work: [Issue #1](https://github.com/AURASymbols/aura-web/issues/1).

### Data model and database
Review schema direction, privacy, constraints, indexes and migration practices. Related work: [Issue #5](https://github.com/AURASymbols/aura-web/issues/5).

### Web3 integration
Review read-only NFT verification, chain handling, RPC failure states and ERC-1155 edge cases. Related work: [Issue #3](https://github.com/AURASymbols/aura-web/issues/3).

### Identity architecture
Review challenge generation, expiry, signature verification, replay protection and data minimization. Related work: [Issue #4](https://github.com/AURASymbols/aura-web/issues/4) and [Issue #6](https://github.com/AURASymbols/aura-web/issues/6).

### Frontend and accessibility
Test mobile navigation, keyboard access, responsive layout, loading/error states, contrast and semantic HTML.

## How to propose work

1. Open or comment on the relevant GitHub Issue.
2. Describe the problem and why it matters.
3. Suggest a small first change and how it can be verified.
4. Align on scope before large implementation work.
5. Submit a focused pull request with tests or reproducible checks.

## Compensation, IP and access

AURA is not announcing a standing salary, grant, equity or token compensation program. Any paid work must be agreed in writing before it begins, including scope, payment, timing, intellectual-property ownership, confidentiality and termination terms. No future token reward should be assumed.

Do not request or share production credentials, wallet seed phrases, private keys or personal secrets. Contributors should use their own development environment and test credentials.
